夜景パースをAIに頼むとき、多くの人が書いているのはプロンプトではありません。**願望**です。「照明を高級感のある感じで」「ハイテクな夜の雰囲気」「情緒的に」。高級感が何を指すのか、モデルには分かりません。

壁を一面だけ取り上げてみます。初心者はこう書きます。*ウォールウォッシャーで壁を照らす*。照明デザイナーはこう書きます。*笠木部に設置したウォールウォッシャーで下方向へ照射、3000K、滑らかで均一なグラデーション*。差は語彙ではありません。4つの決定です。**器具をどこに取り付け、どちらへ向け、色温度は何ケルビンで、光が面に何をするか。**

照明デザインを10年やってきました。これはその中で使っている構成を、そのまま写して使えるように書き出したものです。末尾に実プロジェクトの完全なプロンプトを2件付けます。

## 専門的なプロンプトはちょうど4段でできている

**第1段——役割文。** モデルに立場を与え、タスクを固定します。

> あなたはオフィスビルの照明デザイナーです。この昼景を夜景照明のシーンに変換してください（シーンは変更しないこと）。

「シーンは変更しないこと」は入れる価値があります。これがないと、モデルはついでにあなたの建物を設計し直してよいと解釈します。

**第2段——部位リスト。** ここがプロンプトの本体であり、仕事の中身です。光る部位ごとに1行、そして各行が4つの決定をすべて持ちます。**部位＋器具＋照射方向＋色温度＋光の効果。**

**第3段——全体要求。** 雰囲気に1行、画質に1行、そして時刻に1行（「20時30分」と「深夜」はまったく違う絵になります）。

**第4段——禁止条件。** 望まないことを明示的に書きます。白飛びやホットスポットの禁止、建物の輪郭をなぞる輪郭照明の禁止。夜景パースがおかしく返ってくるとき、10回のうち9回は「書き足りなかった」のではありません。**禁じ足りなかった**のです。

もう一つ知っておくと役立つこと。昼の写真でファサードに強い影が落ちている場合は、第3段に「影を補正する」を足してください。

```
あなたはオフィスビルの照明デザイナーです。この昼景を夜景照明のシーンに変換してください（シーンは変更しないこと）：
- 塔屋頂部：四面の矩形フレーム——高出力の腰壁埋込型器具でガラスのフレーム構造をウォッシュ、暖色3000K。
- 塔屋頂部：頂部内側の植栽——地中埋込スパイクライトで樹冠をアップライト、暖色3000K。

- 塔部ファサード：ガラスのない開放テラス——地中埋込アップライトでテラスの軒天を均一にウォッシュ、低照度、素材の質感を繊細に、暖色3000K。
- 塔部ファサード：テラスの植栽——スパイクライトで樹冠をアップライト、暖色3000K。
- 塔部ファサード：軒天と植栽はトーンと色温度を統一すること——設計者が一体の要素として設計している。
- 塔部内部：低レベルのオフィスの漏れ光、点灯している階と消灯している階を混在、リアルな室内の灯り、ファサード照明より暗く、色温度は2200-4000Kでランダム。

- エントランスと1階の柱：エントランス庇に埋込ダウンライトで機能照明、柱は地中埋込アップライトでグレージング、暖色3000K。
- エントランスとL1-L2の室内：暖かく迎え入れる雰囲気、高輝度、2700K。

- 低層棟ファサード：左側低層棟のフレーム——地中埋込ウォールウォッシャーでフレーム上端のスラブをアップライト、高輝度、暖色2700K。
- 低層棟ファサード：大面積の石壁——ポール設置の投光器で石を均一にウォッシュ、暖色3000K。
- 低層棟のエントランスと室内：暖かい室内、高輝度、2700K。

- ランドスケープ：植栽帯の街路樹——暖色の地中埋込アップライトで樹冠を照らす、3000K。
- 道路：LED街路照明、均一な配光、画面内で最も明るい要素、温白色4000K。
- 交通：長時間露光による赤と白の車のライトトレイル、清潔で活気ある都市の空気感。

- 全体の雰囲気：調和が取れ、明暗の階層が明快、ハイエンドな夜景写真の品質。
- 画質：元の解像度を維持、8K相当のディテール、素材の質感をシャープに。
- 空：20時30分を想定。
- 白飛びやホットスポットは厳禁。建物の輪郭をなぞる輪郭照明は厳禁。
```

このプロンプトの中で、専門的に読めるかどうかを分けている点が3つあります。

**建物を垂直方向に3つの区画——頂部、ファサード、低層部とエントランス——に分け、各区画を内側から外側へ記述している。** コア、次に植栽、次にカーテンウォール。空間の論理をモデルに与えれば、モデルは空間の論理で照らします。順不同のリストを与えれば、返ってくるのも順不同のリストです。

**室内の漏れ光を2200K〜4000Kでランダム化している。** 色温度が均一であることは、パースを嘘くさく見せる最短経路です。実際のオフィスタワーの20時半は、残業している階も、空の階も、暖かいデスクライトの階も、寒色の天井照明の階もあります。室内のランダム性こそが、目に画像を受け入れさせる要素です。

**明るさは最大化ではなく序列化されている。** 道路が最も明るく、次にエントランス、次にファサード、室内が最も暗い。プロンプト内のすべての部位が「明るくしてくれ」と要求すれば、画面の中で明るいと読める要素はなくなります。暗い部位は無駄な余白ではありません。**構図はそこから生まれます。**

## テンプレート2：メディアファサード

別の建物、そして意図的に別の扱い方です。

```
あなたはオフィスビルの照明デザイナーです。この昼景を夜景照明のシーンに変換してください（シーンは変更しないこと）：
- 塔屋頂部：カーテンウォールの垂直アルミフィン内部にライン照明、そのままファサードへ連続させる、寒色白4000K。
- 塔屋頂部：コア部——ウォールウォッシャーで均一にアップライトし、ガラス越しに明快に読めるようにする、暖色3000K。

- ファサード：垂直フィン内部のライン照明でメディアファサードを構成、内容は白黒グレーの水墨画イメージ、寒色白4000K。
- ファサード内部：低レベルのオフィスの漏れ光、点灯している階と消灯している階を混在、ファサード照明より必ず暗くすること、2200-4000Kでランダム。

- 低層棟ファサード：垂直フィン内部のライン照明、内容は暖色の揺らぐ水面の効果、3000K。
- 低層棟の店舗内部：柔らかく均一な室内の灯り、ファサードのライン照明より暗く、暖色2200K。

- 1階エントランスと室内：暖かく迎え入れる雰囲気、高輝度、2700K。

- ランドスケープ：街路樹を暖色の地中埋込器具でアップライト、3000K。中庭の芝生に庭園灯、樹木は3000Kでアップライト。
- 道路：LED街路照明、均一、最も明るい要素、温白色4000K。
- 交通：長時間露光による赤と白のライトトレイル。

- 全体の雰囲気：調和が取れ、明暗の階層が明快、ハイエンドな夜景写真の品質。
- 画質：元の解像度を維持、8K相当のディテール、素材の質感をシャープに。
- 空：20時30分を想定。
- 白飛びやホットスポットは厳禁。輪郭照明は厳禁。
```

分け方に注目してください。メディアファサードは4000Kの寒色で水墨画のコンテンツ、一方で低層棟は3000Kと2200Kの暖色に振って店舗の雰囲気をつくっています。ゾーンごとの暖寒対比は設計判断です。画面全体を一つのトーンで通すのは初期設定であり、初期設定は初期設定に見えます。

**「8K」についての正直な注記。** プロンプトの中の「8K」はスタイルキーワードです。細部の緻密さとシャープな質感の方向へモデルを引っ張ります。解像度の設定ではありません。現在のAI画像生成は、LDRを含めて4K出力が上限です。効果があるので書きますが、8Kのファイルが出てくると期待してはいけません。

## 逆プロンプト法

これを最も速く身につける方法は、逆から回すことです。いいと思った夜景パースを見つけたら、任意の高性能AIにアップロードして、これを送ってください。

```
この夜景パースを分析してください。光っている部位ごとに、次を出力してください：部位（器具の取付位置）、器具の種類、照射方向、色温度、明るさの序列（最も明るい／二番手／暗い）、光の効果（均一／グラデーション／スキャロップ）。あわせて、全体の雰囲気を一文で、夜の時刻、そして画面内で最も暗い3箇所を挙げてください。
```

これを良い画像10枚に対してやると、4つの決定は「確認するチェックリスト」ではなく、照明の見え方そのものになります。

## 構成は写せる。中身の判断は写せない。

どちらのテンプレートも、今すぐモデルに貼り付けて使えます。貼り付けられないのは、各行がなぜそう書かれているかという理由のほうです。

あの部位リストの1行1行は、誰かがすでに下した判断です。テラスの軒天にはダウンライトではなく地中埋込アップライトを使うこと。室内はファサードより暗くしなければタワーが提灯に見えてしまうこと。画面内で最も明るいのは道路であること。テンプレート1が効くのは、通りの向かいから撮ったタワー＋低層棟の構図です。あなたの建物はその建物ではありません。自分の敷地に差し替えた瞬間から、それらの判断は自分で下すことになります。

これがLDRの2つのモードについての、正直な言い分です。**レンダリングモード**は、自分で全部決めたいときのためのものです。プロンプトはあなたが書き、システムは禁止条件のほうを握り続けるので、うっかりした「もっと明るく」がモデルを説得してあなたのファサードを輪郭照明にしてしまうことはありません。**Chat Agentモード**は、そうしたくないときのためのものです。昼の写真をアップロードすれば、AIが部位リストを自分で書き、あなたはそれを読んで承認する。約1分後にパースが届きます。それが[この対になるもう一方](/ja/blog/night-rendering-without-writing-prompts)です。

どちらでも4つの決定は同じです。違うのは、誰がそれを決めるかだけです。

## よくある質問

**このテンプレートは他のAIツールでも使えますか？** 構成そのものは普遍的です。「高級感を出して」よりも「部位－器具－照射方向－色温度」のほうに、どの高性能画像モデルもよく反応します。LDRのレンダリングモードの中では2点が違います。禁止条件がモデルの裁量ではなくシステム側で強制されること。そして、ゼロから建物を生成するのではなく、実在する自分の敷地の写真を変換していることです。

**4段構成はインテリアやランドスケープにも使えますか？** 使えます。骨格は変わりません。役割文をその分野のものに差し替え、部位リストを空間の順序で書き、禁止条件を残す。ランドスケープのリストは長くなりがちです。植栽を樹種と樹高で個別に書くためです。

**どこまで細かく書けば十分ですか？** 光る部位ごとに1行、各行に4つの決定すべて、加えて禁止条件。ここには有用な副作用があります。**1行が書けない部位は、まだ設計できていない部位です。**

この水準で書いたプロンプトで、100点満点の60点あたりまで来ます。その先は語数の問題ではありません。昼の写真の上に器具の位置をマークし、キャンバス上で注記することです。[AI修正で画像がぼやける理由と3つの対策](/ja/blog/why-ai-edits-get-blurrier)を参照してください。

**特定の言語で書く必要はありますか？** 自分が考えるときの言語で書いてください。意味を運んでいるのは構成であって、言い回しではありません。

## 自分のプロジェクトで試す

[LDR](https://app.ldr-design.com)を開いて無料の5クレジットを受け取り、自分の昼景画像を1枚、自分で書いた部位リストとともにレンダリングモードに通してみてください。そのあと同じ画像をChat Agentに通して、見比べてください。比較のほうが、どちらか一方の結果より多くを教えてくれます。
