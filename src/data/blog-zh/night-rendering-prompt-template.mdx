用 AI 生成夜景效果图，大部分人写的不是提示词，是**许愿**："灯光高级一点""科技感夜景""氛围感拉满"。AI 不认识"高级"。

同样给一面墙做灯光，新手写的是：*洗墙灯照亮墙面*。专业的写法是：*洗墙灯装在檐口，往下照，色温 3000K，光线均匀渐变*。差的不是词汇量，是四件事：**灯装在哪、朝哪照、什么色温、打在材质上是什么光效。**

我做了 10 年照明设计。这篇把专业夜景提示词的写法拆成一个可复制的结构，文末附两个真实项目的完整提示词，直接抄。

## 一、专业提示词就四段

**第一段 · 角色句** —— 给 AI 一个身份，锁死任务边界。

> 你是办公建筑照明设计师。将白天的景观转换为灯光夜景（保持场景不变）。

"保持场景不变"这句必须写。不写，AI 顺手就把你的建筑也重新设计了。

**第二段 · 部位清单** —— 主体部分，功夫全在这里。一行一个部位，每行都要凑齐四件事：**部位 + 灯具 + 照射方向 + 色温 + 光效**。

**第三段 · 整体要求** —— 氛围一句、画质一句、天空时刻一句（"晚上 8 点半"和"午夜"是两张完全不同的图）。

**第四段 · 严禁句** —— 不想要什么，必须明写出来："严禁出现过度曝光及明显曝光点""严禁建筑勾勒轮廓的灯光"。夜景图翻车，九成不是没写够，是**没禁够**。

还有一条实用技巧：白天图立面上有明显阴影的，在第三段加一句"修复阴影"。

```
你是办公建筑照明设计师。将白天的景观转换为灯光夜景（保持场景不变）：
- 高层建筑塔冠：建筑塔冠的四个面的矩形框架，采用大功率窗台灯，把玻璃框结构面照亮，暖色3000K色温。
- 高层建筑塔冠：建筑塔冠的内部有绿植树，安装地埋插泥灯照亮树冠，暖色3000K色温。

- 高层建筑立面：建筑立面无玻璃露台，采用地埋灯往上均匀照亮露台的天花，低照度、均匀、材质细腻，暖色3000K色温。
- 高层建筑立面：建筑立面无玻璃露台的绿植，采用插泥灯照亮绿植树冠，暖色3000K色温。
- 高层建筑立面：建筑立面无玻璃露台的天花+绿植，灯光氛围和色温要保持统一和谐，建筑师设计是连贯的整体效果。
- 高层建筑立面室内空间：室内低照度的办公内透，有明有暗，真实的内透效果，亮度低，相对弱化建筑立面灯光的亮度，色温2200-4000K色温随机。

- 高层建筑入口和一层立柱：建筑的入口的雨棚安装下照筒灯，为入口提供功能照明，建筑的立柱安装地埋灯照亮一层立柱结构，暖色3000K色温。
- 高层建筑入口和一层二层的室内空间：暖色的迎宾温馨环境，亮度高，暖色2700K色温。

- 低层建筑立面：左侧的低层建筑框架采用地埋洗墙灯，往上照亮框架的顶板，亮度高，暖色2700K色温。
- 低层建筑立面：建筑立面大块的石材墙面，采用立杆泛光灯，均匀照亮石材立面，暖色3000K色温。
- 低层建筑入口和室内空间：暖色的室内环境，亮度高，暖色2700K色温。

- 植物照明：道路两侧的绿化带乔木，采用暖光地埋灯上照树冠，暖色3000K色温。
- 道路照明：市政道路采用LED路灯照明，均匀照亮路面，亮度最高，暖白4000K色温。
- 道路汽车和车流线：市政道路上的汽车，延时摄影的红白车流线，车前灯暖白光和车尾灯红色光，营造干净和繁华的氛围。

- 整体氛围：整体光环境和谐美观，明暗层次分明、高品质的夜景摄影质感。
- 画质要求：保持原图高清像素，8K画质，材质细节和纹理质感清晰。
- 天空夜景：要求模拟晚上8点半的光环境时刻。
- 严禁出现过度曝光及明显曝光点，严禁建筑勾勒轮廓的灯光。
```

这条提示词里有三个专业细节值得展开，它们是"看着专业"和"看着假"的分界线。

**建筑按三段拆：塔冠 → 立面 → 裙楼/入口，每一段再由内及外描述**（核心筒 → 绿植 → 幕墙玻璃）。你按空间逻辑喂给 AI，它才按空间逻辑打光；你给它一份乱序清单，它还你一张乱序的图。

**室内内透的色温是"2200-4000K 随机"。** 统一色温是让效果图露馅最快的方式。真实的写字楼晚上八点半，有人加班有人走了，有的层是暖色台灯有的层是冷白顶灯——色温随机的内透，眼睛才肯相信。

**整张图的亮度是排过座次的，不是拉满的**：路面最高 → 入口高 → 立面中 → 内透最低。每个部位都喊"要亮"，就等于都不亮。暗区不是浪费掉的画面，**画面的层次正是从暗区来的**。

## 三、完整模板二：幕墙媒体立面

换一栋楼，也是刻意换一套打法。

```
你是办公建筑照明设计师。将白天的景观转换为灯光夜景（保持场景不变）：
- 建筑塔冠：建筑塔冠幕墙竖向铝槽内安装线条灯，延伸至建筑立面，冷白光色4000K色温。
- 建筑塔冠：建筑塔冠的核心筒，采用洗墙灯往上均匀洗亮核心筒，透过幕墙玻璃能看见清晰的核心筒，暖黄光色3000K色温。

- 建筑立面：建筑立面竖向铝槽采用线条灯，营造媒体立面，内容是黑白灰的中国山水意象效果，冷白光色4000K色温。
- 建筑立面室内空间：室内低照度的办公内透，有明有暗，真实的内透效果，亮度低，必须弱于建筑立面灯光的亮度，色温2200-4000K色温可以随机。

- 裙楼立面：建筑裙楼立面竖向铝槽采用线条灯，裙楼立面内容营造暖色波光粼粼的效果，采用暖色3000K色温。
- 裙楼立面：裙楼商业空间的室内光环境是均匀柔和的内透光，效果弱于立面线条灯，暖色2200K色温。

- 底层入口和室内空间：暖色的室内环境，营造迎宾氛围，亮度高，暖色2700K色温。

- 植物照明：道路两侧的绿化带乔木，采用暖光地埋灯上照树冠，暖色3000K色温。
- 建筑之间中庭景观照明：中庭内草坪安装庭院灯，植物安装暖光地埋灯上照树冠，暖色3000K色温。
- 道路照明：市政道路采用LED路灯照明，均匀照亮路面，亮度最高，暖白4000K色温。
- 道路汽车和车流线：市政道路上的汽车，延时摄影的红白车流线，车前灯暖白光和车尾灯红色光，营造干净和繁华的氛围。

- 整体氛围：整体光环境和谐美观，明暗层次分明、高品质的夜景摄影质感。
- 画质要求：保持原图高清像素，8K画质，材质细节和纹理质感清晰。
- 天空夜景：要求模拟晚上8点半的光环境时刻。
- 严禁出现过度曝光及明显曝光点，严禁建筑勾勒轮廓的灯光。
```

注意这个场景的分区处理：媒体立面走 4000K 冷白 + 山水内容，裙楼却刻意转暖（3000K / 2200K）做商业氛围。**冷暖分区是设计判断**；全图一个调是默认值，而默认值看上去就是默认值。

**关于"8K 画质"的诚实说明**：提示词里的"8K"是唤起高细节质感的风格词，不是分辨率设置。目前 AI 生图（包括 LDR）的输出上限是 4K。写它有用，但别指望真拿到一个 8K 文件。

## 四、进阶：反推提示词学习法

学这套东西最快的方式是倒着跑。看到一张你服气的夜景图，把它传给任何一个能读图的 AI，发这段话：

```
分析这张夜景效果图，逐个发光部位输出：部位（灯装在哪）、灯具类型、照射方向、色温、亮度层级（最亮/次亮/弱）、光效（均匀/渐变/光斑）。另外告诉我：整体氛围一句话、拍摄时段、画面里最暗的三个区域。
```

反推十张好图，那四件事就不再是一份你要对照的清单，而变成你看灯光的方式。

## 五、结构可以抄，判断抄不走

两个模板你现在就可以粘进任何一个模型里。抄不走的是**每一行为什么这么写**。

那份部位清单里的每一行，都是有人事先做过的判断：退台天花该用地埋上照而不是下照筒灯；内透必须压在立面之下，否则整栋楼变成一个灯笼；路面得是全画面最亮的东西。模板一适用的是"塔楼+裙房、马路对面机位"这一类构图——**你的楼不是那栋楼**，换成自己的场地，这些判断立刻又回到你手上。

这也正是 LDR 两种模式各自诚实的用途。**渲染模式**给想自己做每一个判断的人：提示词你写，而系统守着那些硬约束——一句随手加的"再亮一点"，说服不了它去给你的立面勾轮廓。**Chat Agent 模式**给不想写的人：传白天图，AI 自己把部位清单写出来，你读一眼、点确认，约 1 分钟出图。那是[这一对文章的另一半](/zh/blog/night-rendering-without-writing-prompts)。

四件事一样都不少，区别只在于谁来做决定。

## 常见问题

**这套模板在别的 AI 工具里能用吗？**
结构是通用的——任何一个像样的生图模型，吃"部位-灯具-方向-色温"都比吃"高级一点"要好得多。在 LDR 渲染模式里有两点不同：那些严禁句由系统守着，而不是指望模型自觉；以及你是在改写自己场地的真实照片，不是凭空生成一栋楼。

**室内和景观项目也能用四段式吗？**
能。骨架不变：角色句换成对应专业，部位清单按空间逻辑逐行写，严禁句照写。景观的清单通常更长，因为植物要按品种和高度分开列。

**提示词写到什么程度算够？**
每个发光部位一行、四件事齐全，再加严禁句。这里有个有用的副作用：**你写不出来的那个部位，就是你方案里还没想清楚的部位。**

提示词写到天花板大约是 60 分。再往上，靠的不是更多的词，而是在白天图上画点位、用画布标注——见[《AI 改图越改越糊的真相》](/zh/blog/why-ai-edits-get-blurrier)。

**必须用某种语言写吗？**
你用什么语言思考就用什么语言写。承载意思的是结构，不是措辞。
